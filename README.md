# QuickNotes

QuickNotes is a simple and efficient note-taking web application designed to help users capture and organize their everyday tasks directly in the browser. It features categorized notes, local storage persistence, and real-time search functionality.

## Features
- Add and delete notes instantly.
- Categorize notes into Personal, Work, or Study (color-coded).
- Real-time search to easily find specific notes.
- Character limit validation (maximum 200 characters).
- Data persistence using browser `localStorage` (notes survive a page refresh).
- Responsive layout that adapts to mobile screens.

## How to run locally
1. Clone this repository or download the project files.
2. Open the project folder in VS Code.
3. Right-click on `index.html` and select **Open with Live Server**.
4. Alternatively, you can just double-click the `index.html` file to open it directly in any modern web browser.

## What I learned

- How to use `localStorage` (with `JSON.stringify` and `JSON.parse`) to save and retrieve data across browser sessions.
- How to implement real-time search filtering using JavaScript array methods.
